# Results of the paper runs (core grid: seeds 42 to 46; other configurations: seed 42)

Produced by `src/date_pipeline.py` on two Kaggle Tesla T4 GPUs (about 4 hours). Re-create all derived files with `python analysis/run_all.py` or rebuild the tables from the saved folds with `ANALYZE_ONLY=1 RUN=all python src/date_pipeline.py`.

| Folder / file | Content |
|---|---|
| `tables/summary_all_configs.csv` | one row per configuration: cross-validation, pooled out-of-fold and test metrics (with bootstrap CIs) |
| `tables/calibration_single_vs_ensemble.csv` | ECE/Brier of single models vs the ensemble, temperature scaling, small-sample ECE bias |
| `tables/config_comparisons.csv` | McNemar, paired bootstrap and Nadeau-Bengio tests against the full DATE configuration |
| `tables/per_fold_metrics.csv`, `confusion_and_perclass.csv`, `threshold_sweep_date_full.csv`, `cost_sensitive_thresholds.csv`, `risk_coverage.csv` | fold-level results, confusion counts, operating points, selective prediction |
| `tables/robustness_and_fairness_probes.csv`, `slice_analysis.csv`, `external_transfer.csv`, `prior_shift_analysis.csv`, `augmentation_studies.csv`, `classical_baselines.csv` | robustness, lexical slices, external hate-speech transfer, class-prior shift, augmentation studies, TF-IDF baselines |
| `tables/dataset_stats.json`, `latency_env.json`, `run_config.json` | dataset statistics (with SHA-256), latency and library versions, run configuration |
| `exports/` | all out-of-fold and test errors, the seeded 60-post samples, top-50 high-confidence errors, TF-IDF top features, vocabulary log-odds |
| `audit/` | near-duplicate audit, language distribution |
| `runs/<config>_s42/fold<k>.npz` | per-fold predictions (out-of-fold, test, inner-validation, perturbed and external sets), loss history, selected epoch |
| `run.log` | the complete log of the run |
| `figures/` | a selection of generated figures (all figures are regenerated by `analysis/`) |

Not included: the augmented-text cache (`aug/`, 29 MB, regenerated deterministically) and model weights (not saved; fold probabilities are).

Note: the file `tables/external_transfer.csv` comes from the first complete run, because the Kaggle session that produced the five-seed results could not load the second external hate-speech set; the other files come from the five-seed run (45 run folders, including DeBERTa-v3).
